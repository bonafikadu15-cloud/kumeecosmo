# Kumee Cosmo 🛒
**Premium TAFLEN Wholesale Platform**

Kumee Cosmo is a specialized digital wholesale ordering application designed to streamline the procurement process for pharmacy and retail partners. The platform enables efficient, real-time selection of TAFLEN cosmetic and medical supplies, featuring integrated invoice calculation and direct Telegram order dispatch.

## 🚀 Key Features
*   **Dynamic Inventory Management**: Real-time interaction with the TAFLEN product catalog, including the full Paraffin series, Baby oils, Jelly, and medical alcohol.
*   **Automated Invoice Calculation**: Instant sub-total and manifest generation as items are added to the order.
*   **Telegram Integration**: Seamless order transmission via the Telegram Web App, ensuring prompt communication between wholesalers and clients.
*   **Settlement Protocol**: Built-in support for both Cash on Delivery (COD) and Bank Transfer verification, including secure attachment handling for deposit receipts.
*   **Admin-Ready Console**: Integrated administrative toggle controls to manage UI visibility and inventory availability.

## 🛠️ Technical Stack
*   **Frontend**: HTML5, CSS3 (Tailwind CSS)
*   **Core Functionality**: JavaScript (ES6+), Telegram Web App API
*   **Deployment**: Web-based deployment for seamless integration within the Telegram ecosystem.
